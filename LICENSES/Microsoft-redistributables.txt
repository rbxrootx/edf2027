Microsoft redistributable files in this package
===============================================

These files are Microsoft's, not part of this project, and are included unmodified so
the game runs without a separate installer and loads known-good versions from its own
folder:

  concrt140.dll, msvcp140.dll, msvcp140_1.dll, msvcp140_2.dll,
  msvcp140_atomic_wait.dll, msvcp140_codecvt_ids.dll, vccorlib140.dll,
  vcruntime140.dll, vcruntime140_1.dll, vcruntime140_threads.dll
      Microsoft Visual C++ runtime, from the Visual Studio "Redist" folder
      (VC\Redist\MSVC\<version>\x64\Microsoft.VC14x.CRT). Redistributed under the
      Microsoft Visual Studio license terms for distributable code (app-local deployment).
      https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files

  d3dcompiler_47.dll
      Microsoft HLSL compiler, from the Windows SDK "Redist\D3D\x64" folder. Redistributed
      under the Windows SDK license terms for distributable code. The game compiles the
      original game's shaders with it at run time; shipping it keeps the compiler the same
      on every machine, including Wine/Proton, whose own d3dcompiler_47 differs.
